Case Study 04 / Personal · iOS app

Gratuity — a brutalist tip calculator.

Free iOS tip calculator with a $2.99 one-time Pro unlock. Designed and built solo; shipped under Tesoro Industries LLC.

TL;DR

Bill in, tip and split out, one screen. $2.99 once unlocks three more themes, bill history, and a Home Screen widget. React Native + Expo + RevenueCat; four weeks from blank file to App Store.

01

The calculator

Bill, tip, total, per-person, keypad. Three presets, a tip nudge, a split stepper, round-up. No onboarding, no account.

02

Rounding rules

Round up rounds the total, not the tip

$187.20 at 20% = $224.64. Round-up: total $225.00, tip $37.80 (20.19% effective). It rounds the total — the number you write on the slip — not the tip.

The split rounds up, so the table never comes up short

Per-person rounds up, so the group never collects less than the bill:

Four settings, and no more

Default tip, default split, round up by default, remember last used. No currency picker, no tax handling, no receipt scanner.

03

Four themes

Same layout in all four themes; only typeface, ground, and ink change. Concrete is free.

The picker previews the live total

Each theme previews on the same live total, locked or not.

Concrete Free

Black pixel type on cream. The free default.

Neon Arcade Pro

Green phosphor on black.

Diner Receipt Pro

Brown on pale green; perforated divider.

Banker Pro

Serif in dark green.

04

One purchase, no subscription

$2.99, once — no subscription. Unlocks three themes, bill history, and the widget. The free tier is a complete calculator with no ads.

05

Privacy

No network except StoreKit. Data lives on-device; history reaches the widget through an App Group. Delete the app and everything goes with it.

  • Network requestsNone, except Apple StoreKit for purchase and restore
  • AccountNone. There is nothing to sign in to.
  • AnalyticsNone. No SDK, no events, no identifiers.
  • StorageLocal app storage, on-device only
  • Widget transportApp Group shared container — never leaves the device
  • AdsNone, on either tier
06

Four weeks to the App Store

Scope fixed at v1 + widget. No tax field, receipt scanning, currency picker, or cloud sync.
